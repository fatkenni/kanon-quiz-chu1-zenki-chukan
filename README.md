# 果音ドリル セットアップガイド

このフォルダのファイルを公開すれば、果音ちゃん専用の学習アプリとして使えます。

## ファイル構成

```
kanon-quiz/
├── index.html             メインのアプリ本体
├── manifest.json          PWAマニフェスト（アプリ情報）
├── sw.js                  オフライン動作用 Service Worker
├── icon-512.png           アプリアイコン（高解像度）
├── icon-192.png           アプリアイコン（中解像度）
├── apple-touch-icon.png   iPhone用アイコン
├── favicon-32.png         ブラウザタブ用アイコン
└── README.md              このファイル
```

これら全部を1つの場所にまとめて公開する必要があります。

---

## 方法A：Netlify Drop（最速・5分）

GitHubアカウント不要。ファイルをドラッグ&ドロップするだけ。

### 手順

1. ブラウザで **<https://app.netlify.com/drop>** を開く
2. このフォルダ全体（または中のファイル全部）をドラッグ&ドロップ
3. 数秒待つと、`https://○○○.netlify.app/` のようなURLが発行される
4. 「Site overview」画面で「Domain settings」から、URL名を覚えやすいものに変更可能
   例：`kanon-quiz.netlify.app`、`kanon-drill.netlify.app` など
5. そのURLを果音ちゃんに送る

### メリット
- アカウント不要（あとでアカウント登録すれば管理可能）
- 数分で完了
- URLは永続

### 内容更新したいとき
新しいファイルを再度ドラッグ&ドロップで上書き。または、Netlifyアカウントを作成してダッシュボードから管理。

## 方法B：GitHub Pages（永続・推奨）

GitHubアカウントを作って、リポジトリにファイルを上げて公開。

### 事前準備

GitHubアカウント未取得なら：<https://github.com/signup> で無料登録

### 手順

1. GitHubにログイン後、右上「+」 → **「New repository」**
2. Repository name に **`kanon-quiz`**（または好きな名前）を入力
3. **「Public」** を選択（Pages無料利用に必要）
4. **「Add a README file」** にチェック
5. 「Create repository」をクリック
6. 作成されたリポジトリ画面で「Add file」→「Upload files」
7. このフォルダの **全ファイル**（README.md含めて全部）をドラッグ&ドロップ
8. 下にスクロールして「Commit changes」
9. リポジトリの **「Settings」** タブを開く
10. 左メニューの **「Pages」** をクリック
11. 「Source」を「Deploy from a branch」、Branch を **`main`** にして Save
12. 数分待つと、上部に「Your site is live at https://（ユーザー名）.github.io/kanon-quiz/」と表示される
13. そのURLを果音ちゃんに送る

### メリット
- 完全無料・無期限
- バージョン履歴が自動で残る
- URLが永久に変わらない

### 内容更新したいとき
- 私が新しい `index.html` を作って渡します
- リポジトリ画面で `index.html` を開く → 鉛筆アイコン（編集）→ 内容を差し替え → Commit
- または「Add file」→「Upload files」で既存ファイルを上書き
- 数分で公開URLにも反映される

## iPhone でアプリ化（ホーム画面追加）

果音ちゃんに以下の手順を教えてください：

1. **Safari**（必須・Chromeでは不可）で公開URLを開く
2. 下の「共有」ボタン（□に↑の矢印）をタップ
3. メニューから **「ホーム画面に追加」** をタップ
4. 名前を確認して右上「追加」
5. ホーム画面に **果音アイコン**（ピンク・パープルのグラデに「果」）が登場！
6. アイコンをタップすると、Safari UIなしの **フルスクリーンでアプリ起動**

### オフラインで使える
一度アクセスすればService Workerが全ファイルをキャッシュするので、電波がない場所（電車内・通学路）でも問題集を解けます。学習記録もそのまま端末に保存されます。

---

## 注意

- **学習記録は端末ごとに分離されます**（PCとスマホで別記録）
- 端末間でデータを同期したい場合は、アプリ内の「⚙ 学習データの書き出し・取り込み」を使う
- アプリを再インストール（ホーム画面から削除→再追加）した場合は記録が消える可能性があるので、大事な節目では書き出ししておくと安心

---

## 困ったとき

- アイコンが正しく表示されない → ブラウザのキャッシュを一度クリア
- Service Worker が更新されない → URL末尾に `?v=2` などを付けて再読み込み
- ホーム画面追加でフルスクリーンにならない → Chrome ではなく Safari で開いてから追加する

更新版が必要な場合は、いつでもClaude会話で指示してください。
